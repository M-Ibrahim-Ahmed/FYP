**Background:** Dark gradient (Navy blue #1a1a2e to Dark purple #16213e)

**Content:**
```

│                                          │
│   [Icon 64px]    ScamShield              │
│                  Real-Time URL Scanner    │
│                                          │

└──────────────────────────────────────────┘
```

**Fonts:**
- Title: Bold, 32px, White
- Subtitle: Regular, 18px, Light gray
- Features: Regular, 14px, White

**Colors:**
- Primary: #6366f1 (Indigo)
- Background: Dark gradient
- Text: White (#ffffff) and light gray (#cbd5e1)

### Tools to Create:

1. **Canva.com** (easiest, free)
   - Template: Custom 440×280px
   - Drag and drop elements
   - Export as PNG

2. **Figma.com** (professional, free)
   - Create frame 440×280px
   - Design and export

3. **PowerPoint/Google Slides**
   - Set slide to custom size: 440×280px
   - Design
   - Export as PNG

### Assets Needed:
- Your icon: `icons/icon128.png`
- Screenshot of extension (optional background)

### Export Settings:
- Format: PNG
- Resolution: 72 DPI minimum
- Size: Exactly 440×280 pixels
